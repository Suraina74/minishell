# Description

minishell is a small Unix-like shell written in C. It provides a command-line interface for executing programs, 
handling built-in commands, managing environment variables, and supporting basic shell features such as pipes, 
redirections, and signal handling.

# Instructions

Clone this project, then:

``` make ```

To execute the program:

```./minishell```
You can then type commands just like in a regular shell.

To cleanup:

```make clean```

To cleanup .o files and the executable:

```make fclean```
